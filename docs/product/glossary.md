# Glossary

| Term | Meaning |
| --- | --- |
| **Drill** | The hands-on exercise unit: starter code, a reference solution, hidden properties and seeded-bug variants, run on the formal tool. This is the only word to use for it. The word it replaced is banned in code, UI, docs and data. |
| Level | Basic, Intermediate or Advance. |
| Content entitlement | A record that lets a learner open one level's lessons, Drills and answers until its end date. |
| Tool entitlement | A separate 3-month window for running Drills on the formal tool. |
| Window | The start-to-end period of an entitlement. |
| Upgrade | Buying a higher level while a lower one is active; priced as the difference. |
| Question bank | Public list of interview questions, each tagged with the companies that asked it. Answers are paid. |
| Company tag | A company (for example Infineon, Qualcomm) shown as logo plus name on a question. |
| Industry Ready | Separate tab of career services. Only Resume Builder and CV screening work today. |
| Run | One execution of a learner's code on the solver for a Drill. |
| Solver | The formal-verification service (FastAPI + OSS CAD Suite: Yosys and SymbiYosys). |
| Runner | An isolated container that executes one solver job. |
| Watermark | Visible and invisible per-user marks on everything a signed-in learner sees. |
| Entitlement | Short for content or tool entitlement. |
| Admin | A user with an admin role in Payload: Author, Editor, Support or Owner. |
