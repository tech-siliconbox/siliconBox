# Content guidelines

The content is the author's own copyrighted material. Do not copy text, figures or Drills from formal.org or any other course.

## Format

- Text, code and diagrams only. No video.
- Lessons are structured blocks (heading, paragraph, code, assertion snippet, callout, diagram).
- Diagrams are SVG or diagram data rendered inline.
- Call exercises **Drills**.

## Lessons

- One idea per lesson. Start with what the learner will be able to do.
- Mark the free preview lessons in front matter (`preview: true`).
- Every code sample compiles or runs on the solver.

## Drills

- Level, topic, top module, mode, depth and timeout in front matter; values stay within the level caps.
- Reference solution and hidden properties are private.
- At least one seeded-bug variant.
- Publish only after the reference PASSes and every variant FAILs on the real solver.

## Questions

- Company tags need a year and a source note. The answer is stored separately from the public text.

## Review

Author drafts, Editor reviews and publishes. Preview as a learner before publishing.
