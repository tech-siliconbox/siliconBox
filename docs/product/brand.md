# Brand

- Name: SiliconBox. Domain: siliconbox.in.
- Logo: a black and white chip-and-cube icon, `apps/web/public/brand/siliconbox-logo.png`.
- The icon and the word "SiliconBox" are separate. The word is live text next to the icon, so either can change without redrawing the other.
- Tab and home-screen icons are made from the same logo, cropped so the chip fills the square: `apps/web/src/app/favicon.ico` (16, 32 and 48 px), `icon.png` (192 px) and `apple-icon.png` (180 px on white, since iOS fills transparency with black). Next adds them to every page; the Payload admin uses them too. Remake all three if the logo changes.
- No tagline for now.
- Theme and type: see `docs/design/`. Light theme only.
