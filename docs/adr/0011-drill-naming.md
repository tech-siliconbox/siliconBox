# 0011. Use the word Drill for the exercise unit

- Status: Accepted
- Date: 2026-10-01

## Context

The founder requires a different English word from the one formal.org uses.

## Decision

Use Drill in code, UI, docs, data and URLs. The earlier word is banned.

## Consequences

A naming check (the `/check-naming` command) runs before tasks finish. Copied reference material must be cleaned.
