# 0015. Company tags show logo and name

- Status: Accepted
- Date: 2026-10-01

## Context

Questions carry the companies that asked them (for example Infineon, Qualcomm). The founder wants both a logo and text.

## Decision

Keep a companies list (name, slug, logo file). Show logo with the name beside it. Tag only what can be sourced, with year and source note.

## Consequences

Logos are trademarks; permission or usage terms must be checked. Until then, show the name only.
