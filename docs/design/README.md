## How to use

- Light theme only. Fonts: Geist and Geist Mono from Google Fonts.
- Use the tokens as the base stylesheet; Tailwind 3 and shadcn/ui conventions are assumed.
- The aim is the same structure, spacing and feel. Do not copy formal.org's text, logos, images or code; the course content is ours.
- Brand: SiliconBox logo icon plus live text, no tagline. See `docs/product/brand.md`.
