# Grant or change a learner's access (Support)

Use the admin area. Every change needs a reason and is audit-logged.

1. Find the learner by email; confirm identity through the support channel.
2. Open their entitlements.
3. Choose: grant a level, extend a window, shorten a window, or revoke.
4. For content vs tool windows, edit the matching record (`content` per level, `tool`).
5. Enter the reason (support request, refund, scholarship, outage credit).
6. Save. The learner gets the change on their next request.

Never edit entitlements directly in the database.
