# Naming: Drill

The exercise unit is a **Drill**. Use it in code (`drill`, `drills`, `DrillRun`), routes (`/drills/:id`), collections (`drills`, `drill_private`), UI copy and docs.

The previous word for it, "kata" (and "katas"), is banned everywhere. Before finishing any task, search the diff for it (`/check-naming`) and replace any hit.
