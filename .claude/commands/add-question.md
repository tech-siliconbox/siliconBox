Create `content/questions/$ARGUMENTS.md` from `content/questions/_template.md`. Ask for: question text, topic tags, companies that asked it (slug from `content/companies/`), year and source note for each company, and the private answer. Add a missing company to `content/companies/` with a name and a logo file placeholder. Never put the answer in the public text.
